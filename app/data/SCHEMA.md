# 知识库数据 Schema 说明

本目录下的 JSON 文件是系统的知识底座。**每一条记录都带溯源字段**，这是本产品"可溯源"创新点的数据基础。

---

## 一、为什么每条记录都要带溯源字段

本产品的核心机制是「生成—校验—溯源」三层架构：

- **生成**：语言模型负责把结构化事实组织成农户能读懂的话
- **校验**：确定性规则引擎逐条否决不合规的处方
- **溯源**：每一条通过校验的建议都能指回它的数据来源

因此知识库不能是"一堆文本"，必须是**带出处、带核验状态的结构化记录**。
没有溯源字段的记录，在产品里不允许进入处方。

---

## 二、核验状态（`verification_status`）

| 取值 | 含义 | 产品中的行为 |
|---|---|---|
| `official` | 来自官方登记数据（ICAMA 农药登记查询） | 可进入处方，展示登记证号 |
| `verified_by_expert` | 由植保专业人员核验过 | 可进入处方，展示核验人与核验依据 |
| `verified_by_standard` | 团队比对国家标准（如 GB/T 8321）核验 | 可进入处方，展示标准条款号 |
| `seed_unverified` | **种子数据，尚未核验** | **仅用于开发与演示，产品中标记为"待核验"，不作为最终处方依据** |
| `deprecated` | 已失效或已禁用的记录 | 进入禁令校验，用于拦截 |

> 代码中这三类"可进入正式处方"的状态集中定义在
> `app/core/models.py` 的 `TRACEABLE_STATUSES`，新增状态只需改这一处。

### 当前核验进度（2026-10-06）

40 条药剂记录中：

- **6 条已比对国家标准** → `verified_by_standard`
- 34 条该标准未收录对应作物/病害组合 → 保持 `seed_unverified`

已核验的 6 条及其修正内容：

| 记录 | 作物·病害·药剂 | 修正 |
|---|---|---|
| P0035 | 小麦·赤霉病·多菌灵 | 用量 100-150→100 克/亩；间隔期 20→**35** 天；次数 2→**1** 次 |
| P0008 | 番茄·灰霉病·异菌脲 | 间隔期 3→**7** 天（两部分标准冲突，取更保守值） |
| P0006 | 番茄·灰霉病·嘧霉胺 | 用量 60-90 毫升→45-55 克/亩；间隔期 3→**5** 天 |
| P0031 | 小麦·条锈病·戊唑醇 | 用量 15-20 毫升→5-8 克/亩；间隔期 21→**28** 天 |
| P0037 | 小麦·白粉病·戊唑醇 | 同上 |
| P0022 | 黄瓜·白粉病·醚菌酯 | 用量 20-30→13.3-20 克/亩；间隔期 5→**3** 天 |

核验依据：**GB/T 8321 系列国家标准**，已查阅第 9 部分（2009）与第 10 部分（2018）。
第 10 部分由农业农村部提出、农业农村部农药检定所起草，规定 430 种农药在 50 种作物上
580 项合理使用准则。逐条依据写在记录的 `verified_basis` 字段，可直接回查标准条款。

**关于两部分标准冲突的处理**：异菌脲在"番茄 · 灰霉病"上，
第 9 部分（2009）为 50 g~100 g、**7 天**，第 10 部分（2018）为 100 mL~200 mL、5 天。
本记录用量为"50-100 克/亩"，与第 9 部分一致，且两者冲突时取更保守的更长间隔期，
故采用 **7 天**，并在 `verification_note` 中记录了两个来源。

> ⚠️ **仍然存在的边界（务必如实说明，不要淡化）**
>
> 1. **这不是植保专业人员的核验。** `verified_by_standard` 表示"团队比对国家标准"，
>    与"专家核验"是两件事，报告中必须区分表述。
> 2. **国家标准覆盖范围小于农药登记范围。** 未被标准收录的 34 条，不代表登记用法不成立，
>    只代表无法用本标准核验；它们的 `verification_status` 未作任何改动。
> 3. **登记证号仍为空。** GB/T 8321 不含登记证号，需另从中国农药信息网采集。
> 4. **有 1 条标准值比原值更宽松**（P0022 醚菌酯 5 天→3 天），以国家标准为准，已在
>    `verification_note` 中标注。
> 5. 正式应用前仍建议由植保专业人员复核全部 40 条。
> 6. **已查阅 5 个部分（第 5、7、8、9、10 部分），其余部分（1-4、6）尚未获取。**
>    已核验的 6 条之外，其余农药在本标准中或未收录、或仅有其他作物条目
>    （例如代森锰锌见于苹果/西瓜/柑橘，氟硅唑见于黄瓜黑星病而非番茄叶霉病），
>    故无法用现有标准核验。

## 三、文件清单

### 1. `kb_diseases.json` — 病害知识

```jsonc
{
  "disease_id": "tomato_late_blight",   // 唯一标识
  "crop": "番茄",                        // 作物
  "name": "晚疫病",                      // 标准名
  "aliases": ["番茄晚疫病", "疫病"],      // 别名，用于检索与口语匹配
  "pathogen": "致病疫霉 Phytophthora infestans",
  "symptoms": "……",                     // 症状描述，用于诊断说明
  "favorable_conditions": "……",         // 发病条件，用于风险提示
  "severity_levels": ["轻", "中", "重"], // 分级
  "source": "……",
  "verification_status": "seed_unverified",
  "verified_basis": "",        // 核验依据，指向具体标准条款
  "verified_by": "",           // 核验主体
  "verified_date": "",         // 核验日期
  "verification_note": ""      // 与原值的差异说明
}
```

### 2. `kb_pesticides.json` — 药剂登记记录（约束校验的核心依据）

```jsonc
{
  "record_id": "P0001",
  "reg_cert_no": null,              // 农药登记证号；种子集为空，接入官方数据后填写
  "pesticide_name": "烯酰吗啉",
  "formulation": "50%水分散粒剂",    // 剂型
  "active_ingredient": "烯酰吗啉",
  "ai_content": "50%",
  "crop": "番茄",                    // ★ 约束校验字段一：登记作物
  "target": "晚疫病",                // ★ 约束校验字段二：登记防治对象
  "dosage": "30-40克/亩",            // ★ 约束校验字段三：登记用药量
  "dosage_min": 30,                 // 结构化数值，单位见 dosage_unit
  "dosage_max": 40,
  "dosage_unit": "克/亩",
  "application_method": "喷雾",
  "safety_interval_days": 3,        // ★ 约束校验字段四：安全间隔期
  "max_applications_per_season": 3, // ★ 约束校验字段五：每季最多使用次数
  "toxicity": "低毒",
  "banned": false,                  // 是否禁用
  "restricted": false,              // 是否限用
  "source": "……",
  "verification_status": "seed_unverified"
}
```

## 四、约束校验用到的字段速查

| 校验规则 | 依赖字段 |
|---|---|
| 登记作物匹配 | `kb_pesticides.crop` |
| 防治对象匹配 | `kb_pesticides.target` |
| 剂量区间合规 | `dosage_min` / `dosage_max` / `dosage_unit` |
| 安全间隔期 | `safety_interval_days`（对照当前日期与预计采收日） |
| 使用次数上限 | `max_applications_per_season` |
| 禁用/限用拦截 | `banned` / `restricted` / `kb_banned.json` |
| 可溯源性 | `source` / `verification_status` / `reg_cert_no` |
